## 2. Мета роботи

Метою лабораторної роботи є розроблення модульного застосунку мовою Python для обробки інформації про кіносеанси, яка зберігається у CSV-файлах.

У процесі виконання роботи передбачається опанувати роботу з колекціями Python, перевірку коректності даних, читання та запис файлів, використання функцій, автоматизоване тестування, створення програмних пакетів і налаштування кросплатформної безперервної інтеграції.

## 3. Формат вхідних даних

Програма працюватиме з CSV-файлами, які містять інформацію про кіносеанси.

Обов'язковий заголовок CSV-файлу:

```csv
film,hall,start,price,sold
```

| Поле | Опис |
|---|---|
| `film` | Назва фільму |
| `hall` | Назва або номер кінозалу |
| `start` | Дата та час початку сеансу у форматі `YYYY-MM-DDTHH:MM` |
| `price` | Ціна одного квитка |
| `sold` | Кількість проданих квитків |

Для зчитування даних використовуватиметься модуль `csv`, зокрема `csv.DictReader`, із підтримкою кодування UTF-8.

## 4. Заплановані функціональні можливості

Програма повинна забезпечувати:

- Зчитування інформації про кіносеанси з CSV-файлу.
- Перевірку правильності заголовків і значень полів.
- Перетворення текстових значень у відповідні типи даних.
- Фільтрацію сеансів за умовою `sold > threshold`.
- Обчислення виручки окремо для кожного кінозалу.
- Формування множини унікальних назв фільмів.
- Обчислення загальної виручки кінотеатру.
- Визначення найпопулярнішого кіносеансу.
- Формування текстового звіту з результатами аналізу.
- Обробку помилок введення та некоректних даних.
- Запуск програми через інтерфейс командного рядка (CLI).

## 7. Додаткове завдання із зірочкою ⭐

У межах додаткового завдання планується реалізувати потокову обробку великих CSV-файлів без необхідності завантаження всіх записів в оперативну пам'ять.

Для цього використовуватимуться:

- Генератори Python.
- Модуль `itertools`.
- Послідовна обробка записів CSV.
- Модуль `tracemalloc` для вимірювання використання пам'яті.

Передбачається порівняти звичайний і потоковий способи обробки даних, перевірити однаковість результатів та проаналізувати використання оперативної пам'яті.

## 8. Тестування та контроль якості

Для перевірки коректності програми планується використовувати `pytest`.

Тести охоплюватимуть правильні вхідні дані, порожні файли, відсутні стовпці, некоректні числові значення, дублікати, граничні випадки та помилки командного інтерфейсу.

Для перевірки якості й форматування коду використовуватиметься Ruff.

## 9. Кросплатформна автоматизація

У GitHub Actions буде налаштовано автоматизовану перевірку Python-проєкту на трьох операційних системах:

- Ubuntu
- Windows
- macOS

Автоматизація включатиме встановлення залежностей, запуск тестів, перевірку Ruff і створення wheel-пакета.

Налаштування Python не повинні порушувати роботу наявного Java-проєкту.
